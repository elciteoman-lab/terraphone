NASA GPM IMERG & SVS 5650

NASA Space Apps Challenge NASA SVS ID 5650 GPM IMERG V07B Web Audio API

raIn.tensity is an interactive global rain sound simulator designed for the NASA Space Apps Challenge. It transforms near real-time global precipitation data from NASA's Global Precipitation Measurement (GPM) constellation into high-fidelity procedural soundscapes draped across a tactile 3D bumpy globe.

NASA Scientific Visualization Studio (SVS) 5650:
"Near Real-Time Global Precipitation from the Global Precipitation Measurement Constellation"
Visualizations by Alex Kekesi with scientific consulting by Dr. George Huffman. The international satellite constellation integrates GPM Core Observatory, GCOM-W1, NOAA series, Metop, and DMSP to synthesize global rainfall and snowfall measurements every 30 minutes.

Scientific Audio Engine:
Rain acoustics are synthesized mathematically in real-time using the Web Audio API based on the observed rainfall rate (mm/hr) and camera altitude (zoom level). As you zoom in, high-frequency droplet impacts and splash cavitation emerge; zooming out transitions to atmospheric stratospheric rumbles. Severe convective storms (>25 mm/hr) trigger procedural sub-bass thunder rolls.

Keyboard Shortcuts:

• Space Play / Pause rain audio

• H Toggle Zen View (hide/show all UI slowroads-style)
• Right-Click + Drag Tilt and rotate 3D bumpy globe
